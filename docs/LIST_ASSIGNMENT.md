# Assign existing family lists

Choose New list or Manage lists, then Assign existing. Each list name appears once per family. Choose the list to see the family-member checklist.

Checked means the member already has that list. Check an unassigned member you manage to create their own empty, private list immediately. A saved check stays checked; a failed save restores the unchecked state and shows the error in the dialog. Existing assignments cannot be unchecked here, to protect their lists and gifts. Adults with their own accounts control their own assignments.

There is no extra Assign submission or automatic navigation. Done closes the dialog. The existing child-list permission switch applies when assigning a child. No gifts, images, purchases or sharing settings are copied from the source list.
